# Haust Class Schedule APP

河南科技大学课程表应用，比河科大官方课程表好用

## 态度（？）

- `Just for fun but useful`
- 你完全可以在此地任意发挥，即使推送答辩也无所谓，有用并且对你的学习有帮助即可
- 面向新手，完全支持纯vibe

## 技术栈

- Vue 3 + TypeScript
- Tauri（桌面 / Android）

## 如果你是新手

恭喜你来对地方了，你完全可以把这里当作你的新手村关卡。 <br>
在这里你可以

- 加入开发群，结交南娘朋友
- fork或直接在此开发
- 完成修改，开启issue
- 提交PR
- 由我们专业的（专业嘛？AI好像挺专业的 :P ）团队审核

你可以收获

- 来自其他人的经验分享
- 来自审核人员的建议
- 真实项目协作经验
- 为摆脱学校难用的课程表APP，制作并应用你独特设计的功能，让他人看到并使用
