## Default Permission

Allows reading the system bar insets, listening for changes to them, and choosing the status and navigation bar icon style

#### This default permission set includes the following:

- `allow-get-insets`
- `allow-set-bar-style`
- `allow-register-listener`
- `allow-remove-listener`
