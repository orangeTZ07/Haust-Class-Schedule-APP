# 霓虹主题提案（MCP 测试）

> 本文用于验证 GitHub MCP 的分支、提交和草稿 PR 创建流程。仅包含设计提案，未实现主题，不改变应用行为。

## 目标

为课表提供更有动感的可选霓虹主题，同时保持课程名称、时间和地点清晰可读。不修改现有默认主题。

## 视觉方向

- 深色背景搭配青色、紫色和少量粉色高光。
- 课程卡片使用克制的发光边框，避免正文大面积发光。
- 当前日期和当前课程使用明确的文字或图标标识，不只依赖颜色。
- 背景渐变和网格保持低对比度，不遮挡课表内容。

## 动效方向

- 主题切换使用短暂的渐变过渡。
- 当前课程可以使用缓慢的呼吸光效，避免闪烁和频繁脉冲。
- 卡片悬停、按下和弹窗开合使用轻量过渡；触屏交互不能依赖悬停。
- 优先使用 opacity 和 transform 等适合合成的动画；避免大量持续变化的模糊阴影。

## 无障碍与性能要求

- 尊重 prefers-reduced-motion，并提供关闭装饰动效的选项。
- 减少动态效果时应保留静态选中状态及完整功能。
- 验证正文对比度、键盘焦点和课程状态的可辨识性。
- 在桌面及 Android 上检查滚动流畅度、交互响应和持续动画开销。
